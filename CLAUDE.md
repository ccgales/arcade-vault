## Project

## Working with this Next.js version

**Read `AGENTS.md` first — it is loaded automatically above via `@AGENTS.md`.** In short: this project pins a Next.js version (16.3.2) that may differ from your training data in APIs/conventions/file structure. Before writing framework-touching code, check `node_modules/next/dist/docs/` (sections: `01-app`, `02-pages`, `03-architecture`, `04-community`) for the current API instead of assuming prior Next.js knowledge.

`AGENTS.md` itself is regenerated by `next dev` (see `node_modules/next/dist/server/lib/generate-agent-files.js`) — don't remove its content from a diff, and do commit it if it shows as changed.

## Architecture

- **App Router only**, TypeScript, path alias `@/*` → repo root (`tsconfig.json`).
- `app/layout.tsx` — root layout; loads `Geist`/`Geist_Mono` fonts via `next/font/google` and sets them as CSS variables.
- `app/globals.css` — Tailwind v4 (via `@tailwindcss/postcss`, no `tailwind.config.*` — v4 uses CSS-based config).
- Styling is Tailwind utility classes with dark-mode variants (`dark:`) throughout.
- `app/page.tsx` - home route (`/`)
